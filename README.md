# Next.js Dashboard

A modern dashboard application built with Next.js 14, featuring App Router, authentication, and real-time data management.

## Overview

This dashboard application is built following the Next.js App Router course, demonstrating best practices in modern web development with Next.js.

## Features

- 📊 Interactive Dashboard
- 🔐 Authentication System
- 💳 Invoice Management
- 📱 Responsive Design
- ⚡ Real-time Data Updates
- 🎨 Modern UI with Tailwind CSS

## Prerequisites

- Node.js 18.17.0 or later
- npm or yarn package manager
- Git
